# NOVEX — سایت فروش سرویس‌های حجمی

سایت استاتیک (HTML/CSS/JS خالص) و آماده انتشار روی GitHub Pages؛ بدون بک‌اند و بدون نیاز به نصب چیزی.

## فایل‌ها
- `index.html` صفحه اصلی (معرفی، تعرفه‌ها، مراحل، سوالات متداول، تماس)
- `pricing.html` تعرفه‌ها، لیست حجم‌ها و بخش «حجمت را بساز» (کره‌ی انیمیشنی انتخاب حجم و قیمت)
- `style.css` تمام استایل‌ها
- `script.js` تمام تعاملات و **داده قیمت‌ها**

## تغییر قیمت‌ها
فایل `script.js` را باز کن؛ در بالای فایل آرایه `TIERS` است. برای هر دسته `p1` قیمت هر گیگابایت یک‌ماهه و `p2` قیمت دوماهه است. `min` و `max` محدوده حجم و `step` پله‌ی حجم (گیگابایت) هستند. حجم‌هایی که در لیست تعرفه‌ها نیستند با قیمت `CUSTOM` (همان بالای فایل) حساب می‌شوند. همه بخش‌های سایت از همین داده استفاده می‌کنند.

## تغییر اطلاعات تماس
لینک‌های تلگرام و روبیکا در `index.html`، `pricing.html` (پنجره سفارش و فوتر) قرار دارند. لینک تلگرام سفارش در `script.js` در `CONTACT` هم هست؛ با جستجوی `Omid1262` و `oMiD1262` همه را پیدا می‌کنی.

## انتشار روی GitHub Pages
1. در https://github.com/Nightshadowoooo/Novex وارد مخزن شو.
2. روی **Add file ← Upload files** بزن و فایل‌های داخل پوشه ZIP را (نه خود ZIP) بکش و رها کن.
3. روی **Commit changes** بزن.
4. به **Settings ← Pages** برو. در Source گزینه **Deploy from a branch**، شاخه **main** و پوشه **/(root)** را انتخاب و Save کن.
5. بعد از یکی دو دقیقه سایت در https://nightshadowoooo.github.io/Novex/ باز می‌شود.

## به‌روزرسانی
فایل را در مخزن باز کن، آیکون مداد (Edit) را بزن، تغییر بده و Commit کن. چند دقیقه بعد سایت به‌روز می‌شود.

## آزمایش
- دسکتاپ: `index.html` را دوبار کلیک کن تا در مرورگر باز شود.
- موبایل: بعد از انتشار، آدرس سایت را در گوشی باز کن، یا در مرورگر کامپیوتر F12 و سپس آیکون موبایل را بزن.
- فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ بدون اینترنت از Tahoma استفاده می‌شود.
